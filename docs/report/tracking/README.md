# Tracking reports

Thư mục này chứa các báo cáo, audit, benchmark và kết quả thực nghiệm của từng scope tracking.

- `scope01/` đến `scope31/`: evidence theo từng scope.
- Các báo cáo tổng hợp ở cấp thư mục: `TRACKING_TEST_REPORT.md`, `TRACKING_BENCHMARK.md`, `TRACKING_IMPLEMENTATION.md` và `TRACKING_CONFIGURATION.md`.
- Tài liệu có chữ `REPORT`, `AUDIT`, `RESULTS`, `BENCHMARK` hoặc `FINAL` là kết quả/evidence; không dùng thư mục này để lưu kế hoạch mới.
